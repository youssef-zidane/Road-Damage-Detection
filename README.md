# Road Damage Detection System 🛣️

## Overview
This graduation project focuses on building an automated computer vision system to detect and classify road damages (such as potholes and cracks) using deep learning. The system aims to assist municipalities and road maintenance authorities in identifying infrastructure defects accurately and efficiently.

## Dataset
The model is trained on the **RDD2022 (Road Damage Detection 2022)** dataset, which includes diverse images of road conditions from multiple countries.
- **Classes detected:** 
  - Longitudinal Cracks (D00)
  - Transverse Cracks (D10)
  - Alligator Cracks (D20)
  - Potholes (D40)

## Methodology
- **Model:** YOLO (You Only Look Once) state-of-the-art object detection algorithm.
- **Environment:** Kaggle / Google Colab (for GPU training).
- **Web Interface:** A drag-and-drop web application is being developed to allow users to upload images or videos for real-time damage detection.

## Tech Stack
- **Language:** Python
- **Computer Vision & AI:** Ultralytics (YOLO), OpenCV
- **Data Manipulation:** Pandas, NumPy
- **Frontend/Web UI:** Streamlit
